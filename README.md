# Поехали

Мобильный прототип для выбора однодневных поездок по Грузии. Проект на **Expo SDK 57, React Native 0.86 и TypeScript** с навигацией Expo Router. Есть версии интерфейса для iOS, Android и браузера. В репозитории находятся исходники; готовые IPA/APK и публикация в магазинах не входят в этот результат.

## Что работает

- Каталог из шести поездок: поиск по местам, категории, фильтры длительности и сложности прогулки.
- Детали маршрута: остановки, план дня, примерные время и бюджет, ссылки на источники.
- Выбор даты через календарь в нижней панели.
- Реальный прогноз Open-Meteo по остановкам: температура, вероятность осадков, ветер и подсказки по погоде. Есть состояния загрузки, недоступного прогноза и повторного запроса.
- Выбор «В кафе» / «Еда с собой» с изменением оценки длительности дня. Кнопка поиска заведений открывает Google Maps.
- Короткий вариант поездки в Сабадури без озера Сиони.
- Обзорная карта Leaflet с подложкой OpenStreetMap, выбором маршрута и его остановками.
- Избранное, будущая дата поездки, режим питания и тема сохраняются локально через AsyncStorage. Интерфейс сообщает об ошибках сохранения.
- Светлая и тёмная темы; при первом запуске учитывается системная тема.

## Запуск

Нужны Node.js **22.13 или новее**, npm и интернет для установки зависимостей. Выполняйте команды из корня проекта:

```sh
npm install
npm start
```

`npm start` запускает Metro. Для нативной проверки используйте совместимый development build на устройстве или в симуляторе. Нативные зависимости уже перечислены в `package.json`; создание, подпись и установка приложения на устройство — отдельный этап.

Браузерный предпросмотр:

```sh
npm run web
```

Терминал покажет адрес предпросмотра. Команды `npm run ios` и `npm run android` запускают Expo для соответствующей платформы; они сами по себе не создают готовый IPA или APK.

Для текущего локального прототипа ключи API и `.env` не требуются. Погоде и карте нужен интернет.

## Маршруты

| Поездка | Места |
| --- | --- |
| Лес, тишина и Сиони | Сабадури и озеро Сиони |
| Выше двух рек | Джвари и Мцхета |
| Крепость у бирюзовой воды | Ананури и вид на Жинвальское водохранилище |
| Маленький отпуск в Кахетии | Бодбе и Сигнахи |
| Вниз, к водопадам | Каньон Дашбаши / Цалка |
| Город, вырезанный в скале | Уплисцихе |

Каталог хранится в `src/catalog.json`. Это редакционные планы, собранные по открытым источникам; на месте маршруты пока не проверены.

## Текущие ограничения

- Поддерживаются поездки **на машине из Тбилиси** с возвращением в тот же день. Других городов старта, общественного транспорта и многодневных поездок пока нет.
- Длительность, расстояние пешком и бюджет — оценки. Живые пробки, точные автомобильные маршруты и фактическое время прибытия не рассчитываются. В бюджетах отдельно указано, что включено и какие билеты не учтены.
- Заведения пока выбираются через **поиск в картах**. В приложении нет собственной проверенной базы ресторанов, актуальных меню, цен, бронирования или проверки часов работы.
- Прогноз запрашивается на **ближайшие 16 дней**, включая сегодня, в часовом поясе `Asia/Tbilisi`. Для первой остановки используется 11:00, для последующих — 15:00. Это ориентиры для сравнения погоды, а не вычисленное расписание поездки. Доступность отдельных показателей зависит от API; пропуски остаются неизвестными. Ответы кэшируются в памяти на 15 минут.
- Координаты на карте — **обзорные точки мест**, иногда центр водоёма или точка фотосъёмки. Они не являются подтверждёнными парковками и входами. Пошаговой навигации и дорожной линии маршрута нет; ссылки на места открывают поиск, чтобы выбрать подъезд.
- Погода не подтверждает проходимость дороги или открытие объекта. Текущие часы работы, билеты и доступ к тропам в каталоге не проверяются автоматически.
- Карта использует публичные тайлы OpenStreetMap с видимой атрибуцией. Она загружает текущую область просмотра и обрабатывает сетевые ошибки; офлайн-карт и предварительной загрузки районов нет. Условия сервиса описаны в [OSM Tile Usage Policy](https://operations.osmfoundation.org/policies/tiles/).
- Избранное хранится на текущем устройстве или в текущем браузере. Аккаунтов и синхронизации между устройствами пока нет.

## Источники и фотографии

Ссылки на [Georgia Travel](https://georgia.travel/), [Агентство охраняемых территорий Грузии](https://apa.gov.ge/en/) и другие источники сохранены у маршрутов и доступны в разделе «Источники и фотографии». Уплисцихе указан в Предварительном списке ЮНЕСКО, а не как уже включённый объект Всемирного наследия.

Авторы, оригиналы, лицензии и условия использования фотографий перечислены в **`ASSET-CREDITS.json`** и данных каталога. Фотографии уменьшены и сжаты для приложения, а в карточках кадрируются под формат экрана. Условия CC BY / CC BY-SA / CC0 относятся к соответствующим изображениям; авторство и ссылки на лицензии нужно сохранять.

Все шесть фотографий включены в приложение и находятся в `assets/photos/`. Соответствие локальных файлов задаёт `src/photos.ts`; при ошибке загрузки интерфейс показывает запасной фон. Изображение Сиони в обложке первого маршрута подписано как озеро, в том числе при выборе варианта «Только лес».

Прогноз предоставлен [Open-Meteo](https://open-meteo.com/). Перед публичным коммерческим запуском нужно выбрать подходящие условия использования погодного API и картографического сервиса.

## Проверки

```sh
npm run lint
npm run typecheck
npm test
```

Тесты проверяют фильтрацию, даты в часовом поясе Грузии, изменение оценки длительности, восстановление избранного, выбор часа прогноза и обработку отсутствующих погодных данных. Проверены lint, TypeScript и 9 автоматических тестов; Expo export успешно собрал JavaScript для iOS, Android и web. В браузере проверены ширины 320 и 390 px, календарь, фильтры, поиск, короткий маршрут, выбор еды, карта, тема и сохранение после перезагрузки. Проверку реального отображения, жестов и внешних ссылок на iOS и Android выполняют отдельно на устройствах.

## Где менять код

- `src/app/` — экраны и навигация Expo Router.
- `src/ui/` — интерфейс, календарь, фильтры, темы и состояние приложения.
- `src/model.ts` — фильтрация, даты и расчёт редакционных оценок.
- `src/catalog.json` — маршруты, остановки и источники.
- `src/photos.ts`, `assets/photos/`, `ASSET-CREDITS.json` — фотографии и атрибуция.
- `src/services/weather.ts` — Open-Meteo и обработка прогноза.
- `src/services/RouteMap.tsx` — карта для native и web.
- `tests/` — проверки модели и погоды.
